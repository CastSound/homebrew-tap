# CastSound Homebrew Tap

Custom Homebrew tap for CastSound Desktop.

## Installation

```bash
brew tap castsound/tap https://github.com/CastSound/homebrew-tap.git
brew install --cask castsound
```

Or in one command:

```bash
brew install --cask castsound/tap/castsound
```

## Updates

The cask uses `livecheck` against the latest GitHub release, so `brew upgrade` will pick up new versions automatically.
